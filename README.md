# How To Install
1. Download this as a zip
2. extract
3. download mitmproxy and jellyfin
4. add shows to jellyfin
5. sideload this ipa to your idevice https://archive.org/download/apple-ios-logo-png-open-2000/com.turner.cnvideoapp-iOS4.3-(Clutch-2.0.4).ipa
6. open cn_jellyfin_addon.py in notepad
7. change your_ip to your ip
8. change your_api_key to your api key
9. change your_user_id to your user id
10. run the command at the top from the directory
11. set my idevices proxy to your your pcs ip and the port as 8888
12. open the app
13. done
